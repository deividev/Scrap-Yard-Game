# Scrap Yard Idle — Release Roadmap

> **Última actualización:** Abril 2026  
> **Target plataforma:** Steam (Windows) + Web  
> **Estado actual:** T1-T3 completo, PCB Printer + HDD Assembler integrados, 7 máquinas T4-T7 pendientes

---

## Abril 2026 — Demo + Steam Page + Trailer

**Objetivo:** Tener la demo pública lista, la página de Steam publicada y el primer trailer.

> **Estado de la demo:** ✅ **Cerrada y jugable.** Modal al producir por primera vez con Empaquetadora (T3). ~20-25 min de juego directo, 45-60 min explorando upgrades. El jugador puede seguir jugando pero sin desbloquear nuevas máquinas ni recursos.

### Semana 9-11 abril — 7 máquinas + recursos T4-T7
- [x] PCB Printer integrado
- [x] HDD Assembler integrado
- [ ] Screen Fabricator + recurso Screen
- [ ] GPU Fab + recurso GPU
- [ ] Smartphone Factory + recurso Smartphone
- [ ] Laptop Workshop + recurso Laptop
- [ ] PC Builder + recurso Desktop PC
- [ ] Mining Rig Assembly + recurso Mining Rig
- [ ] Data Center Assembly + recurso Server Rack
- [ ] Todas las imágenes de máquinas y recursos T4-T7 (cards + icons)

### Hasta 20 abril — Sistema de Contratos (F1) para el trailer
- [ ] F1 — Contratos básico: spawn, UI, timer, reward/penalty
- [ ] Grabación de gameplay con todo el contenido (máquinas T4-T7 + contratos)
- [ ] Entrega al publisher para producción del trailer

> **Por qué incluir contratos en el trailer:** Los contratos muestran urgencia (timer), recompensas y decisión activa del jugador — mucho más atractivo visualmente que solo máquinas produciendo. Maximiza el impacto del trailer para los meses de Next Fest.

### Resto de abril — Steam page + Trailer publicado
- [ ] Steam page publicada (capsule art, screenshots, descripción)
- [ ] Trailer publicado
- [ ] Página web del juego publicada
